Java and ICS references

Oracle Java Documentation: ArrayList

I used this to check how Java ArrayLists work, especially methods like add(), get(), set(), remove(), and size(). It helped with my ArrayList tutorial and with explaining the Bridge program, where the deck and player hands change while the program runs.

URL: docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/ArrayList.html

Oracle Java Documentation: Scanner

I used this to review user input in console programs. It connects to programs where the user enters menu choices, names, student numbers, marks, and other information.

URL: docs.oracle.com/javase/8/docs/api/java/util/Scanner.html

Oracle Java Documentation: FileWriter and PrintWriter

These references helped me understand file output, especially saving student data and sorted results into text files. This connected to the file writing part of my Student Marks program.

URLs: docs.oracle.com/en/java/javase/21/docs/api/java.base/java/io/FileWriter.html and docs.oracle.com/en/java/javase/21/docs/api/java.base/java/io/PrintWriter.html

Oracle Java Documentation: String

I used this to check String methods such as charAt(), substring(), equals(), and equalsIgnoreCase(). These methods came up in card programs, search features, and user input checks.

URL: docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html

Oracle Java Documentation: Math

I used this to review Java's Math class for random numbers and rounding. It helped with small details like generating random values and rounding averages.

URL: docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Math.html

Oracle Java Tutorials: Classes and Objects

I used this as a general reference for object oriented programming. It helped me review classes, objects, constructors, attributes, and methods while writing the Learning page.

URL: docs.oracle.com/javase/tutorial/java/javaOO/index.html

Oracle Java Tutorials: Arrays

I used this to review how arrays store fixed size data and how indexes work. It connected to my arrays and 2D arrays explanations in the Learning page.

URL: docs.oracle.com/javase/tutorial/java/nutsandbolts/arrays.html

Oracle Java Tutorials: Swing

I used this as a reference for GUI programming, where buttons, windows, and user actions can trigger code instead of only using the console.

URL: docs.oracle.com/javase/tutorial/uiswing/index.html

ICS4U Class Lessons and Assignments

My class lessons, assignment instructions, and course examples were the base for the topics explained in this portfolio. These included arrays, 2D arrays, ArrayLists, OOP, sorting, searching, recursion, file output, and GUI programming.

Source: ICS4U class material and assignment files from the course.
