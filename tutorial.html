Programming structure tutorial

ArrayLists in Java.

An ArrayList is one of the most useful tools I learned in ICS because it lets a program store a list of items that can change while the program runs. Instead of being locked into one size like an array, an ArrayList can grow, shrink, and adjust as the data changes.

Main idea

A flexible list that can change size.

Think of an ArrayList like a container that can hold many values. In my Bridge program, I used ArrayLists to store the deck of cards and each player’s hand. That made sense because cards are constantly being added, removed, and moved around.

The first thing to remember is that ArrayLists come from java.util, so the import has to go at the top of the file.

import java.util.ArrayList;

ArrayList<String> deck = new ArrayList<>();
ArrayList<String> p1 = new ArrayList<>();
ArrayList<String> p2 = new ArrayList<>();
ArrayList<String> p3 = new ArrayList<>();
ArrayList<String> p4 = new ArrayList<>();

Array vs ArrayList

The difference is flexibility.

FeatureArrayArrayList
SizeFixed after it is createdCan grow or shrink
Accessing valuescards[0]cards.get(0)
Lengthcards.lengthcards.size()
Adding valuesMore manualadd()
Removing valuesRequires shifting items yourselfremove()
Best useKnown, fixed dataData that changes while the program runs

Core methods

The methods I used the most.

add()

Adds a new item to the list. In my Bridge code, each card gets added to the deck first.

deck.add("" + ranks.charAt(j) + suits.charAt(i));

get()

Gets the item at a specific index. Since indexes start at zero, get(0) means the first item.

String card1 = deck.get(0);

remove()

Removes an item from the list. After taking the first card from the deck, I removed it so it could not be dealt twice.

deck.remove(0);

size()

Returns how many items are in the list right now. This is useful in loops because the list can change size.

for (int i = 0; i < deck.size(); i++) {
    // use each card
}

set()

Replaces one value with another. I used this idea when shuffling the deck by swapping two cards.

deck.set(i, deck.get(rand));

clear()

Removes everything from the list. This is useful when restarting or resetting data.

deck.clear();

Real example

Dealing cards with an ArrayList.

This part shows why ArrayLists are useful. The program takes the first card from the deck, removes it from the deck, and adds it to a player’s hand. That is exactly the kind of changing data that ArrayLists are made for.

Line by line, get(0) takes the top card, remove(0) deletes it from the deck so it cannot be used twice, and add() gives that card to a player. Without an ArrayList, this would be more annoying because I would have to manually track empty spaces and shift cards around.

String card1 = deck.get(0);
deck.remove(0);
p1.add(card1);

String card2 = deck.get(0);
deck.remove(0);
p2.add(card2);

Looping through a list

Going one item at a time.

Loops are important because an ArrayList usually has many items. In my Bridge program, I looped through a hand of cards to count points and suits. This helped the program calculate each player’s score instead of checking each card manually.

for (int i = 0; i < hand.size(); i++) {
    String card = hand.get(i);
    char rank = card.charAt(0);
    char suit = card.charAt(1);
}

Common mistakes

Things that confused me at first.

Forgetting the import

If import java.util.ArrayList; is missing, Java will not understand what an ArrayList is.

Using array syntax by accident

Arrays use cards[0], but ArrayLists use cards.get(0). This is one of the easiest mistakes to make.

Mixing up length and size

Arrays use .length. ArrayLists use .size(). The parentheses matter because size() is a method.

Removing while looping

When you remove something, the indexes shift. If I am removing multiple items, I have to think carefully about the loop direction.

Forgetting indexes start at zero

The first item is index 0, not 1. The last item is always size() - 1.

Final takeaway

ArrayLists make programs easier to build.

ArrayLists are useful because they let a program work with changing data. In my Bridge program, the deck and hands had to change constantly, so ArrayLists made the code cleaner and easier to understand.

What I learned: ArrayLists are not just another Java topic to memorize. They are a practical way to organize information when a program needs to add, remove, search, or loop through data.
