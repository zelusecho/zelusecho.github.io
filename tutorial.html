What is an ArrayList?

A flexible list that can change size.

An ArrayList is a resizable list from Java's java.util package. Unlike a normal array, an ArrayList can grow and shrink while the program runs. This makes it useful when a program does not know exactly how many items it will store.

import java.util.ArrayList;

ArrayList<String> names = new ArrayList<>();
Why this matters: Real programs often deal with changing data. A contact list, shopping cart, student database, or playlist can all change while the program is running.

Core methods

add()

Adds a new item to the end of the list.

names.add("Aisha");

get()

Returns the item at a specific index.

names.get(0);

set()

Changes the item at a specific index.

names.set(1, "Zachary");

remove()

Removes an item and shifts later items left.

names.remove(0);

size()

Returns how many items are currently in the list.

names.size();

clear()

Removes every item from the list.

names.clear();

Looping

Going through every item.

A for loop is useful when the index matters. An enhanced for loop is cleaner when you only need the value.

// Regular for loop
for (int i = 0; i < names.size(); i++) {
    System.out.println(names.get(i));
}

// Enhanced for loop
for (String name : names) {
    System.out.println(name);
}

Objects

ArrayLists become powerful with objects.

An ArrayList can store objects, not just strings or numbers. This is useful because a program can store full student records, not just one piece of information at a time.

ArrayList<Student> students = new ArrayList<>();
students.add(new Student("Usayd", 101, 87.5));

for (Student s : students) {
    System.out.println(s.getAverage());
}

Common mistakes

Forgetting the import

Fix: write import java.util.ArrayList; at the top of the file.

Using array syntax

Wrong: names[0]. Correct: names.get(0).

Confusing size and length

Arrays use .length. ArrayLists use .size().

IndexOutOfBoundsException

This happens when the index is too small or too large. Always remember the last index is size() - 1.

Removing while looping forward

Removing shifts indexes. A safer solution is looping backwards when deleting multiple items.

Without ArrayLists

Programming would be longer and more error prone.

Without ArrayLists, programmers would need to manually create larger arrays, copy old values into the new array, track how many spaces are filled, and shift items when something is removed. This would make programs harder to update and easier to break.

Final takeaway: ArrayLists matter because they combine structure with flexibility. They make it easier to write programs that respond to real changing data.
